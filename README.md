# Nmap Engine (`nmap_engine`)

A Flutter package for network discovery, port scanning, and security auditing, ported for native mobile environments.

## ✨ Features

- **Port Scanning**: Fast multi-port state verification.
- **Asynchronous Execution**: Real-time progress updates and non-blocking streams.
- **Mobile Optimized**: Designed for seamless integration into Flutter applications.

## 🚀 Installation

Add this package to your Flutter project's `pubspec.yaml`:

```yaml
dependencies:
  nmap_engine:
    git:
      url: https://github.com/AbdoFawzi777/redops-hub.git
      path: packages/nmap_engine
```

## 📝 Usage Example

```dart
import 'package:nmap_engine/nmap_engine.dart';

void main() async {
  print('nmap_engine initialized successfully.');
}
```
